# muh dotfiles (using caifs)

Dotfiles using (caifs)<https://github.com/caifs-org/caifs>

Featuring:

* [emacs](emacs/) - my custom emacs configuration "he-macs" , focusing on software projects per tab group
* [git-dev](git-dev/) - git dev flow - a split work/private development flow with handy aliases for managing both
* [bash](bash/) - custom bash configuration
* editorconfig - a master editorconfig file that negates the need for per-project editorconfigs....kinda
* starship - fairly standard starship configuration, but it is automatically hooked into bash shell
* tmux - 

Standard in the caifs common repo https://github.com/caifs-org/caifs-common 

## Installing

Everything should be installable on a new system via the [install.sh](install.sh) script.
